# Network Quiz

## Project Overview

Network Quiz is a simple Python quiz program designed to help students practise basic computer networking concepts.

I created this project to improve my Python programming skills and review networking knowledge from my university studies.

## Project Features

- A Python-based networking quiz
- Practice with basic networking concepts
- A small project for learning and improving Python code

## Technologies Used

- Python
- GitHub
- Git version control

## How to Run

1. Install Python on your computer.
2. Download the `Quiz.py` file.
3. Open the file using VS Code or another Python development environment.
4. Run the program using the command `python Quiz.py`.

## Learning Outcomes

Through this project, I practised writing and modifying Python code, identifying errors and improving my programming skills.

I also used GitHub to upload my project and track code changes through commits. This helped me understand the importance of version control in software development.

## Future Improvements

In the future, I plan to improve the quiz by adding more networking questions, improving the user experience and testing the program more carefully.
